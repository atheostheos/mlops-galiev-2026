# Проблемы baseline_notebook.py

Список проблем, мешающих воспроизведению на другой машине:

## 1. Абсолютный путь к данным
```python
df = pd.read_csv("/Users/anna/Desktop/работа/данные/churn_final_v3_ПОСЛЕДНИЙ.csv")
```
**Проблема:** Путь жестко закодирован для конкретной машины (Anna's Desktop).
**Коллега не найдет файл:** `/Users/anna/` не существует на его компьютере.
**Решение:** Использовать относительный путь или переменную в конфиге.

---

## 2. Потеря данных через dropna()
```python
df = df.dropna()
```
**Проблема:** Удаляет весь рядок если хоть в одном столбце пропуск.
**Последствие:** Теряются клиенты и информация о них.
**Что произойдет:** На новых данных может удалиться 30-40% вместо 5%.
**Решение:** Заполнить пропуски осмысленно (median, forward-fill и т.д.).

---

## 3. Ручное кодирование категорических признаков
```python
df["contract_type"] = df["contract_type"].map({"month-to-month": 0, ...})
```
**Проблема:** Жестко закодированное отображение.
**Что сломается:** Если в новых данных появится новая категория — ошибка KeyError.
**Решение:** Использовать `OneHotEncoder` с `handle_unknown="ignore"`.

---

## 4. Отсутствие валидационного сета
```python
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)
```
**Проблема:** Нет отдельного набора для валидации.
**Последствие:** Не можем настраивать гиперпараметры без утечки в тест.

---

## 5. Отсутствие stratify при сплите
```python
train_test_split(X, y, test_size=0.2)  # без stratify
```
**Проблема:** Может привести к дисбалансу классов в train/test.
**Пример:** В train 80% оттока, в test 20% оттока.
**Решение:** `train_test_split(..., stratify=df["churn"])`

---

## 6. Отсутствие random_state (недетерминизм)
```python
train_test_split(X, y, test_size=0.2)  # нет random_state
```
**Проблема:** Каждый запуск дает другой сплит и другие метрики.
**Пример:** Запуск 1 → ROC-AUC 0.782, Запуск 2 → ROC-AUC 0.765.
**Решение:** `train_test_split(..., random_state=42)`

---

## 7. Гиперпараметры в коде, не в конфиге
```python
model = RandomForestClassifier(n_estimators=157, max_depth=9, min_samples_leaf=3)
```
**Проблема:** Параметры жестко закодированы в .py файле.
**Риск:** Чтобы поменять параметры, нужно редактировать код.
**Решение:** Параметры в `params.yaml`, читаются в коде.

---

## 8. Отсутствие сохранения модели
**Проблема:** Модель не сохранена (только в комментарии).
**Риск:** Легко потерять, нет версионирования.
**Решение:** Сохранять через joblib/pickle в `models/`.

---

## 9. Нет сохранения метрик
**Проблема:** Только print(), метрики не в файл.
**Риск:** Как проверить улучшение на следующей итерации?
**Решение:** Сохранять в `reports/train_metrics.json`.

---

## 10. Препроцессор не в модель
**Проблема:** Трансформация данных не сохранена вместе с моделью.
**Сценарий:** API получает новые данные, как их трансформировать?
**Решение:** Pipeline = препроцессор + модель, сохранить вместе.

---
